# Seedance 执行

把镜头意图整理为清晰、可核对的生成输入。保持已确认的角色、造型、场景与摄影选择，不在提示词阶段擅自改写创意。

## 先确定能力边界

区分用户是在准备提示词还是要求实际生成。整理用户已提供的平台入口、模型版本、输入模式、画幅和时长。

涉及时长上限、参考图数量、首尾帧、音频、分辨率、seed、负面提示词或 API 字段时，以当前入口的官方文档或可见界面为依据，记录来源与核对日期。不要把一个平台或版本的能力套到另一个平台。

版本未明确或资料不可访问时，继续输出通用镜头描述，将设置列为“待核对”，不编造参数范围、专用语法或 API。若要实际调用，先确认工具存在、所需素材可用且调用与费用在用户授权范围内；没有执行结果时只交付输入包。

## 组织单镜头输入

优先一条提示词对应一个连续镜头，并依次描述：

1. 主体与关键识别特征：仅保留影响一致性的内容。
2. 场景与初始状态：空间、时间、主要环境关系。
3. 主体动作：按发生顺序描述主要动作和结束状态。
4. 摄影机：景别、构图、运动路径与终点。
5. 光线与质感：主光方向、软硬、色彩和背景层次。
6. 连续性约束：固定的服装、道具、角色数量与下一镜所需姿态。

动作多或镜头运动冲突时先简化。用户要求多镜头片段时，仅在当前版本已核实支持的情况下组织对应输入，否则交付分镜提示词供分别生成与剪辑。

## 参考素材

图生视频先检查已提供图像，识别主体、构图、造型与遮挡，再编写从该图初态出发的运动。无法查看图像时说明限制，不杜撰图像内容。

有多个参考文件时，为每个文件记录用途：角色身份、服装、构图或风格。只有当前入口支持时才使用多个文件或专用引用标记；上传顺序及界面槽位以实际平台为准。参考图与文字冲突时明确指出，并优先保留用户确认的设定。

## 默认交付包

每个镜头提供：

- 镜头 ID 与提示词版本，例如 S001 / v01。
- 可直接复制的中文主提示词；仅在用户或目标工作流需要时提供英文版。
- 素材清单及各自用途；未提供的素材标为缺失。
- 设置表：输入模式、目标时长、画幅、其他设置；区分创作目标与已确认可用的选项。
- 检查重点：角色稳定、动作完成度、镜头运动、物体形态和剪辑接续。
- 已知限制与下一步：待核对事项、是否已实际生成。

避免事项可以作为质量检查清单；不要默认平台存在独立负面提示词字段。时长、画幅等有专用设置时放在设置表中，不将“写进提示词”视为已经配置成功。

示例主提示词（原创、未执行生成）：

> 成年角色穿深灰长外套，站在安静的室内窗边，位于竖画幅右侧。角色缓慢抬眼看向左侧窗外，身体保持原位。眼平中景，摄影机缓慢前移，结束于胸部以上近景。窗侧柔光照亮面部，背景保持暗部层次。全程保持同一角色、服装和窗户位置，结尾保留向左的视线。

## 结果诊断与停止条件

收到视频或可查看帧后，按镜头目标比较实际结果，定位问题属于输入歧义、参考冲突、动作复杂度还是能力限制。没有视频时，可以根据用户描述提出假设，但不声称亲自检查过。

每轮只调整与主要缺陷相关的少数变量；保留镜头 ID、提示词版本、实际设置、素材版本、结果和修改原因。帧图检查不能证明整个视频的时序稳定。

付费重试次数采用用户预算或约定上限，不自行无限重试。同类问题连续两轮没有改善时，建议简化动作、拆镜头或改用后期处理；这是工作流建议，可按用户已授权的方案调整。
